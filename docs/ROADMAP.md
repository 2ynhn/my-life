# 로드맵

## ✅ 1단계 — 읽기 전용 MVP
- [x] 구글 로그인, 허용 이메일(소유자/게스트) 확인
- [x] Drive 폴더 트리 사이드바, 폴더 목록, 최근 수정
- [x] 마크다운 렌더링 (GFM, frontmatter 메타·태그)
- [x] 옵시디언 `![[이미지]]`, `[[링크]]` 변환, 첨부 이미지 서버 프록시
- [x] 모바일 레이아웃, 다크 모드
- [x] 개인정보처리방침 페이지 (OAuth 게시용)

## ✅ 2단계 — 편집 (소유자만)
- [x] 편집기(CodeMirror) + 미리보기, Drive에 저장, Ctrl+S
- [x] 새 파일 만들기 — `_templates` 폴더의 카테고리별 템플릿, 오늘 일기 바로가기
- [x] 이름 변경, 휴지통 이동
- [x] 충돌 감지: 열 때의 내용(md5)과 저장 직전 내용 비교 → 덮어쓰기 / Drive 내용 불러오기
- [x] 브라우저 임시저장, 저장 안 하고 나갈 때 경고
- [x] 옵시디언처럼 줄바꿈 한 번도 줄바꿈으로 표시
- [x] 연도 폴더가 없을 때 자동 생성 (오늘 일기 쓰기 → daily/<올해>, 저장할 때 생성)
- [x] 이미지 업로드: 사진 버튼·붙여넣기·끌어다 놓기, 브라우저에서 긴 변 2000px로 줄여 가까운 attachments 폴더에 저장
