# 로드맵

## ✅ 1단계 — 읽기 전용 MVP
- [x] 구글 로그인, 허용 이메일(소유자/게스트) 확인
- [x] Drive 폴더 트리 사이드바, 폴더 목록, 최근 수정
- [x] 마크다운 렌더링 (GFM, frontmatter 메타·태그)
- [x] 옵시디언 `![[이미지]]`, `[[링크]]` 변환, 첨부 이미지 서버 프록시
- [x] 모바일 레이아웃 (다크 모드는 6단계에서 밝은 화면 하나로 통일)
- [x] 개인정보처리방침 페이지 (OAuth 게시용)

## ✅ 2단계 — 편집 (소유자만)
- [x] 편집기(CodeMirror) + 미리보기, Drive에 저장, Ctrl+S
- [x] 새 파일 만들기 — `_templates` 폴더의 카테고리별 템플릿, 오늘 일기 바로가기
- [x] 이름 변경, 휴지통 이동
- [x] 충돌 감지: 열 때의 내용(md5)과 저장 직전 내용 비교 → 덮어쓰기 / Drive 내용 불러오기
- [x] 브라우저 임시저장, 저장 안 하고 나갈 때 경고
- [x] 옵시디언처럼 줄바꿈 한 번도 줄바꿈으로 표시
- [x] 연도 폴더가 없을 때 자동 생성 (오늘 일기 쓰기 → daily/<올해>, 저장할 때 생성)
- [x] 이미지 업로드: 사진 버튼·붙여넣기·끌어다 놓기, 브라우저에서 긴 변 2000px로 줄여 가까운 attachments 폴더에 저장

## ✅ 3단계 — 탐색
- [x] 캘린더 (파일 이름의 날짜 기준, 글이 있는 달 바로가기), 첫 화면 '지난 오늘'
- [x] 검색: 제목 + Drive 본문 검색 + 글자 단위 직접 훑기(조사·단어 일부도 찾음, 시간 제한 후 '계속 찾기')
- [x] 태그 모아보기 (글의 #태그 누르면)
- [x] Drive 변경 목록으로 30초마다 바뀐 것만 확인 (내용만 바뀌면 그 자리에서 갱신, 15분마다 전체 다시 읽기)

## ✅ 4단계 — 여러 사람·게스트 (Drive 권한 기반)
- [x] 누구나 구글 로그인 → 각자 자기 Drive의 my-life (토큰은 암호화된 로그인 쿠키에만, 서버 저장 없음)
- [x] 게스트 초대 = Drive 공유 (보기/편집), 게스트는 자기 토큰으로 읽음, 해제 = 공유 끊기
- [x] 게스트에게 숨길 폴더 = Drive 접근 제한 (`.private` 앱 규칙 대체)
- [x] 편집·새 글·삭제 버튼은 Drive capabilities 그대로
- [x] 개발용 가짜 Drive 서버 (`npm run fake-drive`)
- [ ] 접근 기록

## 5단계 — 카테고리별 화면
- [x] purchase: 영수증 한 장 = 글 하나 형식·템플릿, 월별 합계 막대·분류별 막대·이달 목록
- [x] 영수증 자동 입력: 앱 안 카메라로 찍거나 이미지 선택 → Claude(구조화된 출력)로 날짜·가게·금액·분류·품목 채움, 확인 후 저장
  - 사진 파일을 만들지 않음 (메모리에서 바로 전송, 원본 첨부는 선택)
  - API 키는 각자 설정 화면에서 입력, 자기 Drive `_settings/ai.json`에 암호화 저장 (비용은 각자 키로)
- [x] travel: 모든 여행 장소 지도(OpenStreetMap) + 연도별 타임라인, 여행 글에 경로 지도
  - 편집기 '📍 장소 추가': 장소 검색 또는 현재 위치 → 앞머리 `places`에 좌표까지 추가
- [x] health: 숫자 항목마다 선 그래프(평균선, 최근·평균·범위), 기간 선택, 최근 기록 표
- [x] 홈 화면 설치 (웹 앱 매니페스트, 아이콘)
- [ ] 오프라인 읽기, 주기 백업

## ✅ 6단계 — 디자인
- [x] 첫 화면을 쓰임새별 카드로: 일기·구매·여행·건강 (아이콘·색, 이번 달/올해 개수, 바로 쓰기 버튼)
  - 폴더가 없으면 '시작하기'로 만들고 바로 새 글, 나머지 폴더는 '다른 폴더'
- [x] Lucide 아이콘 (머리줄·사이드바·편집기 버튼)
- [x] 항상 밝은 화면 (기기가 다크 모드여도)
- [x] 상단 내비게이션: 경로 표시 대신 ← 위로(폴더 트리 한 단계 위: 글 → 폴더 → 상위 폴더 → 첫 화면) + 화면 이름, 모바일 '폴더' 버튼
- [x] 로그아웃은 설정 → 계정으로 (실수로 누르지 않게)

## ✅ 7단계 — 모으고 활용하기
- [x] 카테고리별 입력 폼 (앞머리 YAML을 주석 그대로 고침, 자주 쓴 값 자동 완성)
  - 건강은 검진 위주: 혈압·혈당·당화혈색소·콜레스테롤·간수치 등, 항목 직접 추가 (컨디션 제거)
  - 일기: 키워드·함께한 사람 칩
- [x] 빠른 한 줄 기록 (오늘 일기에 시간과 함께)
- [x] 공유하기로 저장 (서비스 워커, 파일 안 만듦)
- [x] 모아보기: 사람 · 가게/장소 · 반복 구매(품목 주기, 정기 결제) · 예산(`_settings/budget.json`)
- [x] Claude에게 물어보기 (검색어 추출 → 훑기 → 근거 글로 답, 출처 링크)
- [x] 새 폴더 만들기 (폴더 화면·첫 화면, Drive 권한 따라 보임)
- [x] 속도: 서버 서울(icn1), 누르면 바로 자리표시, 템플릿은 기억해 둔 내용 사용, 일기장 확인·변경 확인 동시 진행, 본 화면 30초 재사용
