# 로드맵

## ✅ 1단계 — 읽기 전용 MVP
- [x] 구글 로그인, 허용 이메일(소유자/게스트) 확인
- [x] Drive 폴더 트리 사이드바, 폴더 목록, 최근 수정
- [x] 마크다운 렌더링 (GFM, frontmatter 메타·태그)
- [x] 옵시디언 `![[이미지]]`, `[[링크]]` 변환, 첨부 이미지 서버 프록시
- [x] 모바일 레이아웃, 다크 모드
- [x] 개인정보처리방침 페이지 (OAuth 게시용)

## 2단계 — 편집 (소유자만)
- [ ] 편집기(CodeMirror) + 미리보기, Drive에 저장
- [ ] 새 파일 만들기 — `config` 폴더의 카테고리별 템플릿
- [ ] 이름 변경, 휴지통 이동
- [ ] 충돌 감지: 열 때의 버전과 저장 직전 버전 비교
- [ ] 브라우저 임시저장

## 3단계 — 탐색
- [ ] daily 캘린더 뷰
- [ ] 전체 검색 (Drive fullText), 태그 필터
- [ ] Drive Changes API로 바뀐 파일만 다시 읽기

## 4단계 — 게스트
- [ ] 게스트는 편집 UI·API 모두 차단 (역할 구분은 1단계에 이미 있음)

- [ ] 접근 기록

## 5단계 — 카테고리별 화면
- [ ] purchase: 월별 지출 합계·차트
